What's in the skill

cutify-ui is an open-source Claude skill for Claude Code, Claude.ai and the Claude API. It gives Claude six themes (Glass, Apron, Picnic, Riso Club, Lantern Night and Toy Box), 19 CSS backdrops, ten open-licence font pairings, pixel-art sprites drawn as SVG, accessible tooltips, and typed React 19 components. Claude uses them to build cute landing pages, product demos, portfolios and multi-agent explainers in React, Next.js or plain HTML. The skill also lists the usual tells of AI-made pages, such as purple gradients, emoji icons and a centred hero over three feature boxes, so the results don't look generated.

Install

In Claude Code, paste this into the chat:

/plugin install cutify-ui --marketplace slyf0xx97/cutify-ui

For Cursor, Codex or another coding agent, run this in your terminal:

npx skills add slyf0xx97/cutify-ui

Then ask for something like "a cute landing page for my study app with three AI tutors". Claude.ai users can upload the zip from the latest release. More in the README.
