Use it

In Claude Code, clone it into your skills folder, then ask for something like "a cute landing page for my study app with three AI tutors".

git clone https://github.com/slyf0xx97/cutify-ui ~/.claude/skills/cutify-ui

For Claude.ai, upload the zip from the latest release under Settings → Capabilities → Skills. More in the README.
