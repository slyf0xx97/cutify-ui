How it works

  1. Forecast AI

    The Forecaster turns weather and meter history into hourly use and solar estimates.

  2. Plan AI

    The Dispatcher drafts when the battery charges and when it sends power.

  3. Check Code

    The safety layer runs six fixed rules and trims anything unsafe.

  4. Approve You

    You see the before and after peak and approve the evening plan.

  5. Run Code

    The inverter follows the approved plan; the safety layer keeps watching frequency live.
