      How it works

      1. 1

        Snap the receipt You

        A photo plus amount, date, category and project code.

      2. 2

        The policy check runs Code

        Meal limit, receipt, project code. Fixable problems go back, judgement calls get a flag.

      3. 3

        Priya approves Manager

        She approves, approves up to the limit, or sends it back with a note.

      4. 4

        Paid in the next pay run Code

        Approved before the cut-off, paid on the run date, trail attached.

      What Tally never does
      • Pay a flagged claim on its ownA flag holds the money until a person decides.
      • Change an amount by itselfOnly Priya can approve less than was claimed, and the trail says so.
      • Lose the trailEvery rule result and decision keeps a name and a time.
